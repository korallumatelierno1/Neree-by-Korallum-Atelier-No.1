# Neree-by-Korallum-Atelier-No.1
Find here user guides, latests updates and more 

To update NEREE, you have to copy and paste the 3 files (called firmware.sha256, auto_update.txt and firmware.bin) on your Nérée micro SD card. Then insert your SD in NEREE and turn it on. An updating display will show off. You can verify your NEREE firmware version in the "about" settings submenu.
